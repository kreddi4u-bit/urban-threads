Urban Threads 

Online Streetwear Store

Urban Threads is a responsive online streetwear store built using HTML, CSS, JavaScript and Firebase. The website allows users to browse products, create accounts, log in and manage their shopping carts.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Firebase Cloud Firestore
- Vercel (Deployment)

Features

- Responsive homepage and navigation.
- Product listings loaded dynamically from Firestore.
- User registration and login.
- Password reset functionality.
- User authentication and logout.
- Shopping cart functionality.
- Add and remove products from the cart.
- Update product quantities.
- Automatic cart total calculation.
- Cart access restricted to logged-in users.

Firebase

Deployment

The project is deployed using Vercel.

Purpose

This project was created as part of a web development assignment to demonstrate front-end development, Firebase integration, authentication and shopping cart functionality.
